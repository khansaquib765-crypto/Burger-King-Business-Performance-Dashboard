# 🍔 Burger Business Performance Dashboard

## 📊 Project Overview

The **Burger Business Performance Dashboard** is an interactive business intelligence project developed using **Microsoft Power BI**.

The project uses burger business sales data sourced from **Kaggle in CSV format**. The raw dataset was first processed and cleaned using **Power Query** before being analyzed and transformed into an interactive Power BI dashboard.

The primary objective of this project is to analyze burger business performance across different dimensions such as:

- Revenue
- Orders
- Quantity
- Categories
- Order types
- Areas
- Products/items
- Monthly sales trends
- Product-level revenue
- Category-level performance

The final dashboard provides a clear and interactive way to monitor business performance and identify important sales trends.
